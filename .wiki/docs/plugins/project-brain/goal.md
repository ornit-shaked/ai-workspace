Our goal is to build a persistent, self-improving AI development environment for a solo developer using Claude Code, Devin, and Cursor — where the file system itself carries the context, so "you don't need to write the perfect prompt, you need a system that remembers". The workspace eliminates repeated feedback by capturing every correction into structured memory (CLAUDE.md, lessons, skills), and separates identity, standards, knowledge, templates, projects, and outputs so context stays fresh and never has to be re-explained. It supports the full lifecycle — idea → PRD → plan → parallel implementation → verification → wrap — through reusable skills, commands, and sub-agents that compound in value with every session.

2. Portability — one repo, clone once, work anywhere
The system must survive machine switches, job changes, and tool switches. This is a load-bearing requirement, not a nice-to-have.

3. Minimize decision friction — the developer should never stop to ask "where does this go?"

4. The system grows senior over time — accumulated experience compounds into pruned, sharpened, promoted structure
