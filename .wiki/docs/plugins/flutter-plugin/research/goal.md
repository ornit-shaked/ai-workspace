7. Implementation Guidance
Implementation agent should inspect the existing Project Brain implementation and reuse its patterns, conventions, structure, installer flow, manifest format, and lifecycle whenever possible.

The goal is consistency with Project Brain, not creation of a parallel solution.

The implementation agent may improve the implementation if a better solution is found.

However:

- Architectural decisions are locked.
- The single-installation experience is locked.
- The Flutter Delta concept is locked.
- Any deviation from the recommended implementation must be documented with rationale.

Implementation details may evolve.

Reuse upstream assets whenever possible.
Do not duplicate Flutter skills.

Keep Flutter Delta small.
